# Revisão do orquestrador — 21/11/2026

Esta versão do script foi preparada a partir da **cópia atual fornecida pelo operador**, incorporando os ajustes encontrados na instalação real do laboratório. A publicação no GitHub **não altera** o arquivo do Ubuntu, as VMs ou o Kubernetes.

## Correções e melhorias

1. Validar acesso ao driver de usuário /dev/vboxdrvu em vez de exigir /dev/vboxdrv como requisito.
2. Gravar corretamente as linhas do known_hosts, rejeitando host keys ED25519 conflitantes.
3. Aplicar 15 GiB de margem ao iniciar e auditar um ambiente registrado, preservando 60 GiB configurados no exemplo para a instalação inicial.
4. Aceitar SHA256 puro ou linha completa do fingerprint copiado do console da VM.
5. Normalizar espaços da autorização interativa sem dispensá-la.
6. Melhorar mensagens de disco e orientação de retomada após Ctrl+C, sem rollback automático.
7. Adicionar oito testes de regressão aos 21 testes originais.

## Testes realizados na revisão isolada

- 29 testes unitários aprovados.
- Python py_compile, Bash bash -n, Ruby ruby -c e Makefile make -n aprovados.

Esses testes **não** demonstram nova instalação no host. Para a validação prática anterior, consulte [o registro de 17/11/2026](validacao-pratica-2026-11-17.md).
