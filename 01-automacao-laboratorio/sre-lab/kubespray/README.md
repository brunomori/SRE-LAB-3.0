# Kubespray upstream

O bootstrap clona a release oficial v2.32.0 no diretório `.local/upstream` e valida o commit em `config/versions.json`. Não versionar nem editar a árvore upstream. Inventário derivado em `.local/inventory/kubespray/hosts.yml` e `group_vars/all.yml`, com grupos `kube_control_plane`, `kube_node`, `etcd`, `k8s_cluster`. O script usa o IP host-only para `ansible_host`, `ip`, `access_ip`; interface real é identificada por SSH. Dependências do upstream ficam em venv separado, conforme requirements.txt da tag. O `ansible.cfg` oficial usa SSH permissivo por padrão, por isso o orquestrador sobrescreve argumentos e host-key checking com configuração local estrita. Não executar playbook upstream diretamente sem guardas de identidade. A validação estática upstream pode ser feita no host após bootstrap, sem conexão a VMs, mas a homologação é posterior.
