# Incident Lab — treinamento offline

Os 16 casos são dados sintéticos. Não usam Kubernetes, não exigem rede e não alteram serviços. `scenarios/` contém alertas e evidências, `solutions/` contém gabaritos separados. O script guarda sessões em `.local/incidents/`, relatórios em `reports/incidents/`. `list`, `show INC-001`, `random`, `evidence 1`, `hint`, `diagnosis 'texto'`, `mitigation 'texto'`, `verify`, `solution`, `close`, `report`, `status`. Para escolher sessão anterior: `./scripts/incident.sh --session ID evidence 1`. O modo aleatório não mostra causa; verify avalia termos, não substitui revisão técnica. `recovery.sh [ID]` abre nova sessão do caso e preserva anterior. É recuperação sintética, não rollback real. Use modelos em runbooks e postmortems. MTTD/MTTR são didáticos.
